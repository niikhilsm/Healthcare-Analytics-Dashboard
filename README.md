
# 🏥 Healthcare Analytics Dashboard using SQL, Power BI & Excel

An end-to-end healthcare analytics project that explores **Obsessive-Compulsive Disorder (OCD)** patient data to uncover demographic patterns, diagnosis trends, and clinical insights. The project demonstrates the complete analytics workflow—from SQL-based data exploration and business analysis to interactive dashboards in **Power BI** and **Microsoft Excel**.

---

# 📌 Overview

Healthcare organizations generate large volumes of patient data that can be transformed into actionable insights through analytics. This project analyzes an OCD patient dataset to answer key business questions regarding patient demographics, diagnosis trends, obsession and compulsion patterns, and clinical severity scores.

The workflow follows a typical data analytics pipeline:

**Data Exploration → SQL Analysis → Business Metrics → Power BI Dashboard → Excel Dashboard → Business Insights**

The project showcases practical SQL querying, business analysis, and dashboard development skills commonly used in healthcare analytics and business intelligence roles.

---

# 📂 Dataset

**Dataset Source**

* **Kaggle:** OCD Patient Dataset

The dataset contains anonymized patient information, including:

* Patient ID
* Age
* Gender
* Ethnicity
* Marital Status
* Education Level
* OCD Diagnosis Date
* Obsession Type
* Compulsion Type
* Y-BOCS Obsession Score
* Y-BOCS Compulsion Score

> **Note:** The dataset is publicly available on Kaggle and is intended for educational and analytical purposes.

---

# 🎯 Business Objectives

The project aims to answer the following business questions:

1. What is the gender distribution of OCD patients?
2. What is the average obsession score by gender?
3. How are patients distributed across different ethnicities?
4. What are the monthly diagnosis trends?
5. Which obsession types are most common?
6. Which compulsion types occur most frequently?
7. What business insights can be derived from the patient data?
